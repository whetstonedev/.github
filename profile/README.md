# Whetstone

**Small tools that sharpen the web you already use.**

Whetstone is an independent software studio building browser extensions.

## Extensions

### Original YouTube Titles

*In review — coming to Firefox Add-ons*

YouTube auto-translates video titles into your interface language. This extension
undoes that: every title shows exactly as the creator wrote it. 12 languages.

## How we build

- **No servers.** Our extensions do their work on your own machine. There is no
  Whetstone backend for them to talk to, because we do not run one.
- **No accounts.** Nothing to sign up for, nothing to log into.
- **No tracking.** No analytics, no advertising, no telemetry — not in the
  extensions, not on our website.

Each extension asks for the narrowest permissions that let it do its job, and its
listing says exactly what it stores and where. Usually the answer is: your settings,
in your own browser.
